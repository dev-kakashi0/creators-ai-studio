# Solenya AI Suite

Je développe une application SaaS appelée Solenya. J'ai déjà un prototype React (interface, navigation et module Ebook). Je veux que tu le transformes en une application complète, professionnelle et prête pour la production.

Objectif

Créer une plateforme tout-en-un permettant aux créateurs de contenu, entrepreneurs et marketeurs de produire rapidement des produits digitaux grâce à l'IA.

L'application doit avoir un design premium comparable à Notion AI, Canva, ChatGPT, Framer ou Lovable.

 Responsive (desktop, tablette et mobile)
